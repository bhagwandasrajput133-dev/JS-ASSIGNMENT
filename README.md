# Classic Snake Game

A web-based classic Snake game built with HTML5 Canvas, CSS, and vanilla JavaScript.

## Features
- Fully client-side, no backend required.
- Responsive design that centers and scales gracefully on smaller screens.
- Keyboard controls (Arrow keys and W/A/S/D).
- Dynamic speed increases as you collect more food.
- Pause functionality with the Spacebar.
- Modern dark theme.

## How to Play
1. Simply open the `index.html` file in any modern web browser.
   - You can do this by double-clicking the file in your file explorer, or dragging and dropping the file into a browser tab.
2. Click **Start Game** to begin.
3. Use the **Arrow keys** or **W, A, S, D** to guide the snake.
4. Eat the red food to grow your snake and increase your score.
5. Avoid hitting the walls or your own tail!
6. Press the **Spacebar** at any time to pause or resume the game.
